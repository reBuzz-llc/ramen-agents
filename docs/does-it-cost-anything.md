---
title: "Does ramen-agents cost anything?"
description: "The software is free, the default free tiers cost $0 in model fees, search is keyless, and a paid provider joins only if you add it by hand."
permalink: /does-it-cost-anything.html
---

The software is free, and the default free tiers cost $0 in model fees. Search is keyless. Free tiers can change, and
if you link billing on a provider's own account, it can charge you. The providers' own pages do not say whether their
free tier needs a card, so read the sign-up page before you add one. When a provider says it is out for now, the next
one answers. If every provider is out, the agent rests until one is back. You need one free model key to start and a
Mac that stays on.
