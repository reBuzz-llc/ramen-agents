# Knowledge base

Standing context for the family, searchable by every bot (`{"type":"search","query":"...","engine":"files"}`):

- `target.toml`: the market the family works right now. One place; cards, bios and starting interests follow it.
- `steers.md`: the owner's directions, newest first, and why they changed.
- `packages-rules.md`: how the packages page is kept.
- `handbook.md`: the formats the cards point at (task brief, package email, outreach task, the lead rule).
- `candidate-feeds.toml`: where Lead Gen's daily list of businesses comes from, per market.

Not rules: the Validator does not enforce what is here. The CEO reads it and sets its own goal from it; the current
goal steers everyone.
