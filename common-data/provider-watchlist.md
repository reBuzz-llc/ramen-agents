# Provider terms watchlist

One line per page the fleet depends on: `- <name> | <url>`. `scripts/provider_watch.py` re-reads these weekly and
reports what changed (free limits, card requirements, retired models). Add a line when a provider joins the chain.

- Groq rate limits | https://console.groq.com/docs/rate-limits
- Gemini API rate limits | https://ai.google.dev/gemini-api/docs/rate-limits
- Gemini API pricing | https://ai.google.dev/gemini-api/docs/pricing
- Speka pricing | https://speka.me/pricing
- Speka models | https://speka.me/models
- Z.ai pricing | https://docs.z.ai/guides/overview/pricing
- Ollama cloud pricing | https://ollama.com/pricing
- Mistral pricing | https://mistral.ai/pricing
- OpenRouter limits | https://openrouter.ai/docs/api-reference/limits
